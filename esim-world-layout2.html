Активация
Установка и активация eSIM
Два сценария: купил дома / активируй уже в стране — это разные шаги.
1
Установите eSIM сразу после покупки — на Wi-Fi дома.
2
Настройки → Сотовая связь → Добавить eSIM → Сканировать QR.
3
Назовите профиль «eSIM.World». Не активируйте «Линию по умолчанию».
4
Включите «Передача данных в роуминге» только для этой линии.

Ошибки
Что делать, если не работает
Самые частые ошибки и быстрые решения. Если решение не сработало — сразу в поддержку.
Код Симптом Решение В поддержку
E-001
Нет интернета после активации
 Включите «Передача данных» и выберите eSIM как «Линию для данных» по умолчанию в настройках Если не помогло за 5 мин — в чат поддержки
E-002
No service / Нет сети
 Перезагрузите телефон, переключитесь на ручной выбор сети, выберите оператора-партнёра вручную Если оператор не находится — поддержка
E-003
Cellular Plan Cannot Be Added
 Проверьте подключение к Wi-Fi и попробуйте eSIM повторно. QR можно использовать только один раз Если QR исчерпан — поддержка восстановит профиль
E-004
QR уже использован
 Не сканируйте повторно. Запросите восстановление профиля в личном кабинете Сразу в поддержку
E-005
Слетели настройки APN
 Настройки → Сотовая связь → eSIM → «Сотовая сеть данных» → APN: esim.world Если APN не сохраняется — поддержка
E-006
Wi-Fi звонки идут, интернета нет
 Отключите VoLTE/Wi-Fi Calling, переключитесь на 4G/LTE only Если не помогло — поддержка
E-007
Как удалить и переустановить
 Настройки → Сотовая связь → eSIM → «Удалить тариф». Затем установите профиль заново через приложение При проблемах — поддержка
E-008
Потерял eSIM при сбросе
 Зайдите в личный кабинет → «Мои eSIM» → Восстановление
